هوش‌یار — نسخه ۵۰ ابزار

محتویات:
- index.html: وب‌سایت کامل تک‌فایلی؛ CSS و JavaScript داخل همین فایل هستند.

روش انتشار در GitHub Pages:
1) فایل ZIP را استخراج کن.
2) فایل index.html را در ریشه مخزن GitHub قرار بده.
3) تغییرات را Commit کن.
4) در Settings > Pages، شاخه اصلی (main) و پوشه ریشه (/(root)) را انتخاب کن.
5) پس از انتشار، آدرس GitHub Pages را باز کن.

ویژگی‌ها:
- ۵۰ ابزار در ۶ دسته‌بندی
- جست‌وجو و فیلتر دسته‌بندی
- آموزش اختصاصی برای هر ابزار
- نمونه درخواست قابل کپی
- لینک مستقیم به وب‌سایت رسمی هر ابزار
- طراحی واکنش‌گرا برای موبایل

نکته: قیمت، امکانات رایگان و دسترسی سرویس‌ها ممکن است تغییر کند. آموزش‌ها راهنمای شروع هستند؛ برای جزئیات جاری به مستندات رسمی هر سرویس مراجعه کن.
